Task 2: Unemployment Analysis

This project explores unemployment trends in India and investigates the impact of the COVID-19 pandemic on unemployment rates.

Project Objectives

- Explore unemployment data.
- Identify unemployment trends over time.
- Investigate the impact of COVID-19.
- Create data visualisations.
- Present findings and conclusions.

Analysis Performed

The analysis identified differences in unemployment rates across regions and highlighted significant changes during the COVID-19 period.
