CodeAlpha – Iris Flower Classification

Project Overview

This project was completed as part of my CodeAlpha Data Science Internship.

The objective is to build a machine learning model that classifies Iris flowers into three species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

Dataset

The dataset contains 150 records and four flower measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

Methodology

1. Data loading and inspection.
2. Data quality checks.
3. Exploratory Data Analysis (EDA).
4. Data visualisation.
5. Feature scaling.
6. Logistic Regression model training.
7. Model evaluation.

Model Performance

The Logistic Regression model achieved 93.33% accuracy on the test dataset, correctly classifying 28 out of 30 flower records.

Key Findings

- The dataset contains 150 records.
- Each species has 50 records.
- No missing values or duplicate records were detected.
- Iris-setosa was classified correctly in all 10 test cases.
- Some overlap exists between Iris-versicolor and Iris-virginica.

Project Files

- "Iris.csv" – Original dataset.
- "CodeAlpha_Iris_Classification.ipynb" – Executable notebook.
- "CodeAlpha_Iris_Classification.pdf" – Project report.

Conclusion

This project provided practical experience in data analysis, visualisation and supervised machine learning using Python.
